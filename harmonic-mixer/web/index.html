how it works
1

scan

Drop in a folder. Harmonizer reads every track — pulling existing key and BPM tags, computing what's missing.

2

analyze

Each track lands on the Camelot wheel. Tempo, key, and energy stored locally so re-scans are instant.

3

mix

Pick a track and see its harmonic neighbors — ranked by key compatibility and BPM, ready for the next drop.
